# dsh-plugin-marketplace

Community plugin marketplace for DeepSeek Harness — browse and install plugins from [awesome-dsh-plugin.com](https://awesome-dsh-plugin.com) directly in the DSH Web settings.

## Install

```bash
dsh plugin --profile web add github:awesome-dsh-plugin/dsh-plugin-marketplace
```

## Features

- 📋 Browse all 190 community plugins from awesome-dsh-plugin
- 🔍 Search by name, description, or author
- 🏷️ Filter by category (UI, Theme, Tools, Workflow, etc.)
- 📋 One-click copy install command to clipboard

## Usage

After installation, open DSH Web → Settings → Plugins → **Community Plugins** tab.
